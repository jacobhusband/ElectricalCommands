## 2. Component Architecture & Relationships

### `apps/ElectricalCommands` (.NET C#)
- **Role**: AutoCAD .NET extension creating custom commands (receptacles, circuiting, lighting plans, panel schedules, wire sizing, tag export/import).
- **Output**: Generates `.bundle` packages and DLLs loaded into AutoCAD.
- **Key Files**:
  - `AutoCADCommands/`: Implementation of custom AutoCAD commands.
  - `ElectricalCommands.sln` and `ElectricalCommands.csproj`: Visual Studio .NET solution and project.
  - `build.ps1` / `build-bundles.ps1`: Bundle packaging scripts.

### `apps/ProjectManagement` (Python + Web UI)
- **Role**: Central desktop orchestration app. Coordinates DWG plotting, project directories, lighting plan scans, wire sizing calculators, and circuit schedule management.
- **Key Files**:
  - `main.py`: Core backend orchestration, local server/API, and CAD script generation.
  - `script.js` & `index.html` & `styles.css`: Interactive UI for project workflows.
  - `lighting_plan.py`: Lighting plan extraction and annotation engine.
  - `ACIES Scheduler.spec`: PyInstaller executable packaging specification.

### Inter-Project Dependencies & Contracts
- **Data Exchange**: `apps/ProjectManagement` executes automated CAD scripts and reads/writes JSON data structures consumed and generated by `apps/ElectricalCommands`.
- When updating data structures or command signatures in `apps/ElectricalCommands`, ensure matching parser logic in `apps/ProjectManagement/main.py` and `script.js` is updated in the same pass.

## 4. Coding & Maintenance Guidelines for AI Agents

1. **Dual-Context Awareness**: Always check if changes in AutoCAD command behavior in `apps/ElectricalCommands` affect GUI inputs or automation scripts in `apps/ProjectManagement`.
2. **Preserve Comments & Standards**: Maintain existing CAD layering conventions, ACIES engineering standards, and docstrings.
3. **Paths**: Use relative paths from repository root or project roots; avoid hardcoded user paths in source files.
4. **No Destructive Overwrites**: Test builds using the portable .NET SDK before finalizing changes.
